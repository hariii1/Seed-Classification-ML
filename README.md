# Seed Classification with Machine Learning

![Python](https://img.shields.io/badge/Python-3.x-blue)
![scikit-learn](https://img.shields.io/badge/scikit--learn-1.0+-orange)

A machine learning project for seed classification using various algorithms and performance evaluation.

## Features

- Data loading and preprocessing
- Multiple ML models:
  - Logistic Regression
  - Linear Discriminant Analysis (LDA)
  - K-Nearest Neighbors (KNN)
  - Decision Trees
  - Naive Bayes
  - Support Vector Machine (SVM)
- Cross-validation and performance metrics
- Model comparison and tuning

## Requirements

- Python 3.x
- pandas
- scikit-learn
- Jupyter Notebook

## Usage

1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Open and run the Jupyter notebook

## Results

Best performing model: **Decision Tree Classifier** with 100% accuracy in cross-validation.
